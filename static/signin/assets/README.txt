Background image
==================

Place your background image here and name it:

  background.jpg

Supported alternatives (edit the path in index.html if you use another name):

  background.png
  background.webp

The stylesheet loads: assets/background.jpg

If the file is missing, a soft grey fallback colour is shown until you add the image.

QR / phone button image
========================

Place your asset next to the background and name it:

  MobilePhoneQRCode2.png

Use a PNG (or WebP) with an alpha channel if you want see-through areas; the
button background is transparent so the app background shows through.

JPEGs have no transparency — export from your editor as PNG with transparency.

If your file uses another name or extension, update the <img src> in index.html.

Centre logo (main screen)
===========================

Add:

  halcyonlogo.png

It is shown centred, with its vertical centre one-third down the main content
area (between the top bar and the footer buttons).
